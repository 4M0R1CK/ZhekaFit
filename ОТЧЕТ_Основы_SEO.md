## Что настроить при публикации на домене

Задать GitHub Actions variable `VITE_PUBLIC_SITE_URL` равным публичному origin. Сейчас в `robots.txt` и sitemap стоит учебный адрес `https://example.com`. На внешнем Supabase API нельзя добавить `X-Robots-Tag` конфигурацией этого nginx; собственного API-маршрута у фронтенда нет. Доступ к данным API ограничивает RLS, а не robots-файл.
